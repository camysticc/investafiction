Changes apply straight away. Search finds a setting by name or by what it does. Presets set many at once: Recommended, Minimal, Accessibility first and Assessment style. Extra settings hide behind **Show more settings**.

Settings marked **affects score** change marking and are recorded on each attempt. Locked settings cannot be turned off. Export and import settings as a file.
