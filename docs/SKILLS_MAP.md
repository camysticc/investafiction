# Skills map

How the features link to the three skills the project is meant to show.

| Skill | Where it shows |
|---|---|
| **OSINT** | Simulated web browser and search with near-miss results; alias and username pivoting; archive snapshots of deleted posts; image geolocation from signs and landmarks; capture discipline with time, address and hash; public versus private material and authority requests; traps for fake personas, repeated focused viewing and collecting about people outside scope. Mostly in *The Last Signal*. |
| **Evidence handling** | Receipt logging, read-only originals and working copies, reasons for accessing originals, a chain of custody per item, an automatic action log, SHA-256 integrity checks against acquisition and import hashes, reporting a hash mismatch without overclaiming, privileged and personal material handled correctly. Strongest in *Quiet Exit*. |
| **Data analysis** | Bank statement and refund analysis, approval limit patterns, call and cell site records, ANPR correlation, file system timestamps and USB history, server and cloud logs, timeline building with clock offsets and time zones, link charts with data-driven suggestions, a map with a time slider. Across all three cases. |
| **Reporting and judgement** | Facts, inferences and assumptions labelled; intelligence grading; corroboration from independent sources; red herrings; stating gaps; cautious attribution; the legality, necessity and proportionality statement. |
